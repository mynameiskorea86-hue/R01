# 부대 소통 활성화 앱 기획서

## 1. 앱 개요
부대 내 소통을 원활하게 하기 위한 모바일형 웹 앱 프로토타입입니다.
가입, 로그인, 지문 인증, 5대 주요 메뉴, 승인 프로세스까지 한 화면에서 확인할 수 있도록 구성했습니다.

## 2. 핵심 기능
- 회원가입
  - 군번
  - 생년월일
  - 부대 코드
  - 사용자 유형 선택
    - 일반 사용자
    - 관리자
    - 지휘자
- 지문 등록 및 로그인
- 메인 메뉴 5개
  1. 방공대 출타신청 종합
  2. 대장과의 대화(마음의편지)
  3. 이발소 신청(두발정리)
  4. 건의사항
  5. 공지사항

## 3. 메뉴 상세 기능
### 3-1. 방공대 출타신청 종합
- 휴가 / 외박 / 외출 중 선택 가능
- 신청 시
  - 시작일
  - 종료일
  - 출타 지역
  - 사용 내역 입력
- 신청 내용은 승인대기 상태로 저장됨
- 최종 승인 권한은 관리자 역할로 처리 가능하도록 구성됨

### 3-2. 대장과의 대화(마음의편지)
- 비밀글 작성 가능
- 작성된 글은 본인과 대장만 확인 가능하도록 안내 표시

### 3-3. 이발소 신청
- 날짜 및 요청사항 입력
- 신청 내역 저장

### 3-4. 건의사항
- 제목과 내용을 입력해 건의 등록 가능

### 3-5. 공지사항
- 부대 공지사항 목록 확인 가능

## 4. 실행 방법
1. 브라우저에서 index.html을 열면 바로 실행됩니다.
2. 회원가입 후 로그인하면 메인 메뉴를 사용할 수 있습니다.
3. 지문 등록과 로그인 버튼은 시뮬레이션 형태로 동작합니다.
